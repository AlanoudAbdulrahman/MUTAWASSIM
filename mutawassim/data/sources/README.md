# بيانات المصادر

`sources.sample.json` **عيّنة توضيحية** لتشغيل النظام فقط. كل حقل `ruling`
ورابط `url` فيها **يجب التحقق منه من دُرر السنية** واستبدال الرابط بالرابط
الدقيق للحديث/الحكم قبل الاعتماد في القياس أو العرض.

الصيغة الموحّدة لكل سجل:

```json
{"id": "...", "text": "<متن الحديث/النص>", "url": "<رابط المصدر الدقيق>",
 "ruling": "صحيح|حسن|ضعيف|موضوع", "source": "dorar.net/hadith", "type": "hadith|quran|..."}
```

يجب أن يحتوي `ruling` على إحدى الكلمات التي يفهمها المحقق (ويُسمح بتوضيح بين قوسين):
`صحيح`، `حسن`، `نص قرآني` ← مؤكد · `ضعيف` ← ضعيف ·
`موضوع`، `باطل`، `لا أصل له`، `ليس بحديث` ← موضوع.
درجة بصيغة أخرى (مثل «منكر») لا يصدر لها حكم، ويُفشلها اختبار `test_verifier_rulings.py`
حتى تُضاف إلى `_RULING_TO_STATUS` في `verification/verifier.py`.

لا تُضف مصادر من خارج قائمة الحزمة المعتمدة.

# وثيقة المصادر المعتمدة (SOURCES)

تحتوي هذه الوثيقة على جميع المصادر الشرعية والعلمية المعتمدة في نظام "مُتَوَسِّم". 
يُمنع منعاً باتاً إضافة أي مصادر خارجية غير مدرجة هنا لتجنب الهلوسة ولضمان دقة النظام.

## جدول المصادر المعتمدة وقواعد الاستخدام

| المجال | المصدر المعتمد | قاعدة الاستخدام | النوع |
| --- | --- | --- | --- |
| **الحديث والأحكام** | [dorar.net/hadith](https://dorar.net/hadith) | لا يُنسب حديث دون حكم معتمد | حكم وإسناد |
| **القرآن** | [quranpedia.net](https://quranpedia.net) | التأكد من موثوقية نقل الآيات | نص وضبط |
| **التفسير والعقيدة والفقه والتاريخ** | [dorar.net](https://dorar.net) | الموسوعة الشاملة للاستدلال | مرجع علمي |
| **الشبهات والأسئلة** | [dawa.center/file/7937](https://dawa.center/file/7937) | مصدر أساسي للحلول الحوارية | ردود معتمدة |
| **المصطلحات** | [islamic-content.com/dictionary](https://islamic-content.com/dictionary) | قاموس مصطلحات مقفل | توطين |
| **المكتبة الشاملة** | [shamela.ws](https://shamela.ws) | المرجع الشامل للكتب | مرجع أصيل |

## التوثيق التقني للروابط
- جميع الروابط يتم تخزينها في الفهرس الداخلي للنظام (`sources.json`).
- في حالة إرجاع نتيجة `confirmed` أو `weak` أو `fabricated` يجب أن تكون مسندة برابط مباشر (`url`) صالح من هذه المصادر حصراً.
- يتم فحص الروابط دورياً باستخدام سكربت `check_links.py` لضمان عدم وجود روابط مكسورة.
